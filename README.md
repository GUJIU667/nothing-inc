# Nothing Inc. / 无事集团

> Do Nothing. Be Everything.

A bilingual, black-and-white website for **Nothing Inc. (无事集团)** — a virtual creative community built around the mission **Creating Infinite Possibilities**.

Live site: https://nothing-inc.bronzecrown2048.chatgpt.site

## Pages

- Home — brand statement and community principles
- About — the non-manifesto and virtual-community clarification
- Careers — self-selected titles and the zero-opening philosophy
- Welcome — local-only virtual onboarding with downloadable PNG offer and employee badge

## Important clarification

Nothing Inc. is a virtual community, not a legal employer. The virtual offer and badge are creative keepsakes only and do not establish recruitment, employment, compensation, or commercial relationships.

## Privacy

V1.0 has no database, analytics, accounts, or form submission. Names and titles entered on the Welcome page remain in the browser and PNGs are generated locally with Canvas.

## Stack

- Next.js-compatible Vinext
- React 19
- TypeScript
- Tailwind CSS
- Cloudflare Workers via ChatGPT Sites

## Local development

Requirements: Node.js 22.13+ and pnpm.

```bash
pnpm install
pnpm dev
```

Production build:

```bash
pnpm build
```
